# Data availability, and the terms that apply

## What is in this package

Stored numeric results only: the output of each analysis, in `results/`.
These are aggregate metrics and score histograms. They contain no
biometric samples, no embeddings, no subject identifiers, and nothing from
which a person could be recognised.

## What is not, and why

| Not included | Reason | How to obtain |
|---|---|---|
| Face images | LFW is a third-party corpus with its own terms | vis-www.cs.umass.edu/lfw |
| Speech audio | LibriSpeech (CC BY 4.0), VCTK (CC BY 4.0) | openslr.org/12, datashare.ed.ac.uk |
| Face and speaker embeddings | Derived from the above; redistributing them would redistribute the corpora in another form | regenerate with the published encoders |
| Frozen IoM projection tensors | Large, and deterministic | regenerated from master seed 2026 |
| `score_histograms.json` | 417 KB, derived | regenerated by `SCOREDUMP.ipynb` |

Embeddings are a derived representation of the underlying biometric
samples, not an anonymisation of them: the inversion analysis in this very
paper reconstructs an input from a protected template. We therefore treat
them as personal data and do not redistribute them.

## Verifying a rerun against ours

`results/external/voice_external_result.json` records SHA-256 hashes of
the VCTK embedding file and manifest used here. A reader who regenerates
the embeddings can compare those hashes before drawing any conclusion from
a difference in results.

## Statements for the manuscript

Copy these into the paper, adjusting the repository URL and DOI.

**Code availability.** The analysis code, the stored numeric results, a
test suite and a verification script are available at [URL / DOI]. The
package includes a script that re-derives every number reported in this
paper from the stored results, and runs with no dependencies beyond the
Python standard library.

**Data availability.** This study used three publicly available corpora:
Labeled Faces in the Wild, LibriSpeech and VCTK, obtainable from their
respective distributors under their own terms. Derived embeddings are not
redistributed, because an embedding is a derived representation of a
biometric sample rather than an anonymisation of it; the inversion
analysis reported here reconstructs an accepted input from a protected
template. Aggregate results sufficient to reproduce every table and figure
are included in the code package. Hashes of the external embedding inputs
are recorded so that a regenerated set can be checked against ours.

**Ethics.** No new human-subject data was collected. All corpora are
publicly released for research use by their distributors. The inversion
analysis attacks templates generated by the authors from public corpora;
no deployed system was attacked and no template belonging to any third
party was used.
